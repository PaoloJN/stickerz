# stickerz.dev

**Your stack, on your laptop.**

Stickerz ([stickerz.dev](https://stickerz.dev)) lets you design your laptop at true size with the logos of your tech stack, then post it or print it.

The logo library started from [svgl](https://github.com/pheralb/svgl) by pheralb. Thank you.

## Run locally

```bash
pnpm install && pnpm dev
```

Copy `.env.example` to `.env` and fill in the variables you need (the database falls back to mock data when `DATABASE_URL` is unset).
